# 核心定义

*这是魔法的基石。*

1.  **内涵**：
	在魔学宇宙中，魔法是对科学的称呼，它是指运用思维形式反映现实世界各种现象的本质和规律的知识体系，是建立在可检验的解释和对客观事物的形式、组织等进行预测的有序知识系统，是系统化和公式化的知识。
2.  **外延 (适用范围)**：
	 它包括门式元素魔法、仪式魔法、天象魔法等，但不包括迷信 、宗教或伪魔法等。

# 特征

*这是魔法的血肉。*

1.  **定义性特征**：
	1. 描述性：可以描述并解释自然现象，提供知识而非判断
	2. 可检验性：原则上可检验可重复实验
	3. 可证伪性：一个魔法理论必须承担被证伪的风险，哪怕延伸出来的魔法成立，知识本身依然能被推翻。
2.  **伴随性特征**：
	1. 数学化：高深的魔法离不开严谨的数学计算，数学化是魔法强大的特征，但不是定义性特征。
	2. 预言性：成功的魔法理论能为魔学发展做出准确的预测，但有些魔法（如战争魔法）预测能力有限。
3.  **内部结构**：
	1. 经验层：从日常生活中可以观察、测量、实验的事实。
	2. 抽离层：归纳事实，得到的象征对应关系。
	3. 理论层：将象征对应关系结合假说构成的逻辑体系，能够施展法术的核心
	4. 世界观：这是魔法的最深层，是基本信念的集合。例如“灵魂是物质的第三种存在形式”、“因果律成立”、“物质决定意识”。这一部分构成魔学活动的基础框架，当这一部分发生变革，就是“魔学革命”（从波粒二象性到灵波粒三象性）。

# 关系

*这是魔法的社交网络。*

1.  **上位概念 (属概念)**：
	- 系统化知识
	- 理性认知活动
2.  **下位概念 (种概念)**：
    - 门式元素魔法
    - 仪式魔法
3.  **同级关联概念 (兄弟概念)**：
	- 数学
	- 逻辑学
	- 哲学
	- 人文学科
	- 工程学
4.  **对立/相关概念**：
    - 伪魔法
    - 非魔法
    - 反魔法
    - 神秘主义

# 实例

*这是魔法的直观展示。*

- 经典施法：通过魔杖、符箓、阵法等人工设备施法
- 自然施法（无杖施法）：不借助外物，通过例如灵根、巫师血统这类灵魂器官施法
- 链上施法：通过远距离法师信号塔实现互联，从线上下载需要的魔法到本地法术位实现新时代施法
