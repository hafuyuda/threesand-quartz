# 核心定义

*这是燃素的基石。*

1.  **内涵**：
	燃素是指物质内部所蕴含的、在宏观上统一表现为热现象的内能。它是对“内能”这一能量形式的别称，虽然称呼上类似某种物质，但强调的是内能通过热的形式在不同物质中表现出来。
2.  **外延 (适用范围)**：
	它包括所有具有内能的物质系统，例如固体、液体、气体、等离子体等。但它不包括机械能、化学能、核能等其他形式的能量，除非这些能量已经转化为物质内部微观粒子的热运动能量（即内能）

# 特征

*这是燃素的血肉。*

1.  **定义性特征 (必备条件)**：
    - 必须是物质内部微观粒子（分子、原子等）热运动动能与相互作用势能的总和。
	- 宏观上必然表现为可感知或可测量的热效应（如温度变化、热量传递）。
	- 本质上是一种能量，遵循能量守恒与转化定律。
2.  **伴随性特征 (常见属性)**：
    - 通常与物质的温度正相关（在无相变情况下）。
	- 通常可以通过做功或热传递的方式改变其大小。
    - 其数值依赖于物质的质量和状态。
3.  **内部结构 (成员关系)**：
    - **最佳代表（原型）**：理想气体的内能，完全由分子热运动的动能构成，与温度严格对应，最纯粹地体现了“热”这一宏观表现。
	- **边界模糊的成员**：0℃的冰水混合物吸收或放出的热量用于改变分子势能，但温度不变，表现不如单纯升温那么直观，但燃素（内能）仍在变化。

# 关系

*这是燃素的社交网络。*

1.  **上位概念 (属概念)**：
    - **能量**。燃素是能量的一种特殊形式，隶属于能量大类，与动能、魔能（电能）等并列。
2.  **下位概念 (种概念)**：
    - 分子动能
    - 分子势能
3.  **同级关联概念 (兄弟概念)**：
    - 机械能
    - 化学能
    - 核能
    - 魔能（电磁能）
4.  **对立/相关概念**：
    - 热、功、温度

# 实例与反例

*这是燃素的直观展示。*

1.  **正面典型实例**：
    - 将一块铁放在火焰上加热，铁的温度升高。此时，铁内部的微观粒子热运动加剧，其内能（即燃素）增加，铁表面变得灼热并向外辐射热量。
2.  **边界案例 (模糊实例)**：
    - 一杯水在室温下自然蒸发。
3.  **明确的反例**：
    一个飞行的子弹具有动能。这颗子弹的机械能（动能）并不直接表现为热——在击中目标前，子弹本身并未因飞行而温度显著升高（忽略空气摩擦）。
