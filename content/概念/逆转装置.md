# 核心定义

*这是逆转装置的基石。*

1.  **内涵**：
	逆转装置（又称魔杖）是一种运用灵波粒三象性原理引导“场—灵—场”转变的炼金装置。它使魔法师得以将意识场转化为非情性灵，再以非情性灵引导情性灵转化为场（或实物），从而实现意识对现实的干涉。
2.  **外延 (适用范围)**：
	它包括各种魔法师使用的魔杖、法杖、权杖等具备逆转场—灵转变功能的炼金装置。它不包括纯粹的施法媒介（如不涉及灵波粒三象性原理的普通道具），也不包括仅用于储存魔力而无逆转功能的容器。

# 特征

*这是逆转装置的血肉。*

1.  **定义性特征 (必备条件)**：
    - 必须基于灵波粒三象性原理运作。
	- 必须能实现“场→非情性灵→情性灵→场”的完整转变链条。
	- 必须能提高低熵体（非以太体）对场的灵敏度。
2.  **伴随性特征 (常见属性)**：
    - 通常具有便于手持的细长外形（如杖状），故俗称“魔杖”。
	- 使用时往往伴随可见或可感的灵波粒效应（如光芒、振动）。
	- 多数逆转装置需要魔法师的精神力或意识场进行激活。
3.  **内部结构 (成员关系)**：
    - 典型代表：标准制式炼金魔杖，完全符合所有定义性特征，结构精巧，专为意识场转化设计。
	- 边界模糊：某些天然形成的灵晶或矿石，可能部分实现场—灵转变但不具备完整三象性原理，算作“准逆转装置”。

# 关系

*这是逆转装置的社交网络。*

1.  **上位概念 (属概念)**：
	炼金装置
2.  **下位概念 (种概念)**：
    - 标准魔杖（个人用便携式逆转装置）
	- 仪式法杖（团体用大型逆转装置）
	- 嵌入式逆转装置（固定于法阵或建筑中的结构）
	- 训练用逆转装置（常以头盔，帽子的形状出现）
3.  **同级关联概念 (兄弟概念)**：
	- 灵魂传感器（灵魂这一灵学量转化为魔力压这一魔学量。）
	- [[逆转模式]]
4.  **对立/相关概念**：
	[[强制逆转装置]]：直接推动灵—场转变的炼金装置

# 实例与反例

*这是逆转装置的直观展示。*

1.  **正面典型实例**：
    - 灰烬制式短魔杖。辞戈文明推出的短魔杖，因为其良好的性能和便于携带的尺寸收到了广大人形魔法师的喜爱。经过约 300 年的市场调研，市面上流传最广的短魔杖，是灰烬 569 型。
2.  **边界案例 (模糊实例)**：
	- 模块化搭载在同频增幅武装外骨骼上的逆转装置。用于快速启动逆转模式，并非主要功能，因此被视为逆转模式的实际运用，而非逆转装置的严格成员。
3.  **明确的反例**：
    普通的木棍或金属棒——即便被魔法师握在手中挥舞，也无法将意识场转化为非情性灵，更不能引导情性灵转化为场。它不具备灵波粒三象性原理的任何机制，缺少定义性特征中的转变链条，因此绝对不是逆转装置。
