## 描述：
行湖针对狐偶准备的行为系统。
在行湖的特化改良下，十二符成为了家用魔偶的自卫系统。
为了保持自卫系统稳定不暴走，行湖整合所有功能后，抽出六张符箓符改造为冷却符。
符箓是狐偶存在的根基，构成角色的基础能力。真正具有能力的只有六张符箓，剩下的六张符箓将作为主线剧情的线索存在。
  

| 符箓     | 分类   | 功能                                 |
| ------ | ---- | ---------------------------------- |
| **子鼠** | 冷却符  | 丰富剧情                               |
| **丑牛** | 箱庭探索 | 冲刺时可破坏特定的墙壁。空放（未撞墙）时，可作为一段短距离位移技能。 |
| **寅虎** | 战斗动作 | 可从背后偷袭未察觉的敌人。消耗内力可召唤短暂的“伥鬼”协助战斗。   |
| **卯兔** | 战斗动作 | 倒地瞬间按下跳跃键可施展“受身”，迅速起身并规避后续压制。      |
| **辰龙** | 冷却符  | 丰富剧情                               |
| **巳蛇** | 冷却符  | 丰富剧情                               |
| **午马** | 战斗动作 | 对韧性归零的敌人施展“处决”，消耗其气血。              |
| **未羊** | 冷却符  | 丰富剧情                               |
| **申猴** | 冷却符  | 丰富剧情                               |
| **酉鸡** | 箱庭探索 | 获得二段跳能力。                           |
| **戌狗** | 基础服务 | 掌握所有基础移动与攻击动作（普攻、冲刺等）。             |
| **亥猪** | 冷却符  | 丰富剧情                               |
